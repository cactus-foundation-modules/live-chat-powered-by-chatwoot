# Live Chat Powered By Chatwoot

Self-hosted live chat for Cactus sites: customers chat (with attachments) from
a click-to-load widget; staff answer from the Cactus admin inbox, a floating
agent console on the public site, or the Chatwoot mobile app. The Chatwoot
server runs on a single Fly.io machine the module can provision itself, backed
by any empty Postgres database, with nightly dumps surfaced on the core
backup page.

See the Cactus wiki page "Live-Chat" for the full setup and architecture.
